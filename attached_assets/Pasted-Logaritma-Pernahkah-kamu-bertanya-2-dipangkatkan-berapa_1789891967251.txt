Logaritma
Pernahkah kamu bertanya, "2 dipangkatkan berapa supaya hasilnya 32?" Itulah logaritma! Yuk, kita kuasai konsep dan 6 sifat saktinya, langkah demi langkah.

a·log b = c  ⇔  aᶜ = b
Pengertian Logaritma
Logaritma adalah kebalikan (invers) dari perpangkatan
Perpangkatan menjawab "hasilnya berapa?". Logaritma menjawab "pangkatnya berapa?".

alog b = c  ⇔  aᶜ = b
a = bilangan pokok (basis), a > 0 dan a ≠ 1
b = numerus, b > 0
c = hasil logaritma (pangkatnya)

💡 Kalau basis tidak ditulis, artinya basis 10. Jadi log 100 = 10log 100 = 2.
Contoh 1: mengubah bentuk pangkat ke logaritma
5² = 25 ⇔ 5log 25 = 2

Pembahasan: basis 5, hasil pangkat 25, pangkatnya 2. Pangkatnya menjadi hasil logaritma.

Pembahasan: tanya "3 dipangkatkan berapa jadi 81?" Karena 3⁴ = 81, maka 3log 81 = 4.

Sifat 1: Penjumlahan
Log ditambah log, numerusnya dikali
alog b + alog c = alog (b × c)
⚠️ Syaratnya: basisnya harus sama.
Contoh 1
2log 4 + 2log 8 = 2log (4 × 8) = 2log 32 = 5

Pembahasan: gabungkan jadi satu logaritma, lalu 2⁵ = 32.

Pembahasan: 6 × 1,5 = 9, dan 3² = 9.

Pembahasan: turunkan pangkat 4 menjadi pengali, lalu 3log 9 = 2.

Ringkasan dan Jebakan Umum
Sifat	Rumus
Dasar	alog aⁿ = n; alog a = 1; alog 1 = 0
1	alog b + alog c = alog (bc)
2	alog b − alog c = alog (b/c)
3	alog bⁿ = n · alog b
4	alog b = plog b / plog a = 1 / blog a
5	glog a · alog b = glog b; gⁿlog aᵐ = (m/n) glog a
6	g(glog a) = a
🚫 Jebakan: alog (b + c) tidak sama dengan alog b + alog c. Yang boleh dipecah hanya perkalian: alog (bc).
